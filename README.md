# StockTracker

台股全市場掃描、個股評分與投資組合管理工具。專案包含 Windows 本機程式與 GitHub Pages 網站；掃描完成後可將最新結果發佈到網站，方便從瀏覽器查看。

[開啟全市場網站](https://timmyhuang0918.github.io/StockTracker/nightly-ranking/)

## 網站功能

### 全市場總覽

- 上市與上櫃指數、成交金額、成交量與相對 20 日平均。
- 市場廣度：上漲／下跌／平盤家數、上漲比例與平均漲跌。
- 近五個交易日的量價、三大法人買賣超、融資餘額、融券餘額與臺指選擇權 P/C 未平倉比率。
- 市場傾向以趨勢、廣度、法人與槓桿資料彙整，僅供觀察，不是買賣或下單指示。

### 族群氣氛

依股票分類呈現族群的漲跌、上漲家數、近五日表現與量能變化。點選族群卡片可直接篩選下方全市場清單；族群資料位於 `docs/nightly-ranking/stock-groups.json`。

### 全市場掃描排名

- 顯示分數、風險、型態、近五日分數、法人買賣超與金額、大戶持股比例／週變化、法人價格敏感度等欄位。
- 可依代號、名稱、價格、漲跌、法人、分數、型態、策略、倉位、法人主導型態與連續分數表現交叉篩選。
- 點選個股可查看完整評分依據、型態、支撐／壓力與交易計畫。
- 可下載目前篩選結果為 CSV。

### 明日交易條件

全市場清單提供「明日交易條件」欄位與篩選：

- **可做・等拉回**：等待回到有效支撐區並止穩。
- **可做・等突破**：等待突破壓力後進入可評估區間。
- **暫不做**：距離支撐過遠、現價已跳過可進區，或停損與第一目標的風報比不足。
- **結構不足**：日 K、ATR 或現價兩側的支撐／壓力資料不足。

條件使用價格結構、ATR、停損風險上限 6% 與第一目標至少 1.5R 的風報比計算。它只幫助篩選與建立觀察清單，**不會自動下單**。

### 個股交易計畫

在個股小卡中可建立隔日交易計畫。系統以支撐、壓力與 ATR 推導買入區、結構失效價、第一／第二目標區，並讓使用者選擇第一壓力區的處理方式。所有操作仍須由使用者自行判斷與手動執行。

### 我的投資組合

- 記錄現股與融資部位、買進／賣出、已實現損益、融資利息、剩餘現金、總資產及持股比重。
- 現金會隨買賣自動增減；融資買進只扣自付額，融資賣出會償還對應融資本金。
- 可區分現股與融資持股、隱藏股數、重設資料，以及以歷史損益調整總資產。
- 網站的投資組合與交易計畫資料只儲存在目前瀏覽器的 `localStorage`；清除網站資料或更換瀏覽器後需自行重新匯入／建立。

## 資料更新流程

本機程式可手動登入後更新三大法人、執行全市場掃描並發佈網站。夜間排程於每日 22:00 依序更新法人資料、刷新主頁股票、掃描全市場、輸出報表與發佈網站。

掃描頁面位於 `docs/nightly-ranking/`；網站頁面會隨發佈結果更新。資料來源、可用交易日與盤後公告時間不同，網站會標示當前可取得的最新日期；缺資料不應解讀為零。

## 本機使用

1. 以 Visual Studio 開啟 `StockTracker.slnx`。
2. 使用 Debug 模式啟動並登入。
3. 在全市場掃描完成後，使用「手動更新網站」將 `docs/nightly-ranking` 的結果發佈。

## 注意事項

本專案提供資訊整理、技術結構與風險觀察，非投資建議，也不連接券商進行自動下單。使用任何價格、交易計畫或持股建議前，請自行確認資料日期、流動性與個人風險承受度。
